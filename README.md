# 🏏 Musa Sports - Premium Product Cards Page

Welcome to the **Musa Sports Product Cards** repository! This project was developed as a frontend task for **Webora Tec**. It is a fully responsive, luxury-themed sports brand webpage built entirely from scratch.

## 🚀 Project Overview

The goal of this project was to create a highly professional, modern, and attractive product cards page displaying five different sports products. The design is inspired by premium international sports brands, featuring a dark theme, glassmorphism, and cinematic typography.

**Strict Constraint Followed:** This project is built using **ONLY HTML5 and CSS3**. No JavaScript, Bootstrap, Tailwind CSS, or any other external libraries/frameworks were used.

## ✨ Key Features

- **Pure HTML & CSS:** 100% vanilla code with no JavaScript or CSS frameworks.
- **Glassmorphism UI:** Premium translucent product cards with subtle glowing borders and soft shadows.
- **Cinematic Typography:** Wide-tracked, high-contrast headings using the *Montserrat* font, paired with clean *Poppins* body text.
- **Smooth CSS Hover Effects:** Cards scale up, images zoom, and buttons glow upon hover using smooth CSS transitions and transforms.
- **Fully Responsive Layout:** Utilizes **CSS Grid** and **Flexbox** to perfectly adapt across Desktop, Laptop, Tablet, and Mobile screens (5 cards on desktop, down to 1 card on mobile).
- **Sticky Glass Header:** A fixed navigation bar with smooth CSS hover underlines.

## 🛠️ Technologies Used

- **HTML5** (Semantic structuring)
- **CSS3** (Grid, Flexbox, Variables, Transitions, Transforms, Backdrop-filter)
- **Google Fonts** (Montserrat & Poppins)
